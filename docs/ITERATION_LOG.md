**发现与处理**
- GPT 在「地狱」档也拿到好结局：难度档的 `drift_scale` 乘的是整段漂移，善治者把漂移压成负数时，乘大反而帮了玩家。模板加 `drift_bias`（先乘后加）；地狱档胡马南牧每季 +0.65、金人轻宋 +0.3、民心 −0.1，开局国库 2300。稳健打法在地狱档好结局 26%（史实 75%）。
- 回执里 `{when}` 未填（模板：摘要也填）；终局那季的远地军报永远到不了（模板：终局补报）；「延至下季结算」被读成要多等一季（模板：改为「延至本季末结算时执行（进入第 n 回合时生效）」；预览写「令达后启程」）；end_turn 标题「已结算至夏」后面列的是春季之事（模板：「春季结算毕，进入夏季」）；兵额为零的军号出现在事实摘要里（模板：不列）；危机分项「其他」含未到军报（模板：注明）。
- 剧本：助辽写「十万石」实扣 100（万石）→ 改「百万石」；王黼「专政日久」「宰相」随路线出错 → 改中性措辞；王黼罢相照例事件在太师已有人时半途失败 → 拆成「蔡京复起 / 不复起」两版；辽主「自夹山遣使、部众离散」在辽强时不符 → 改写；大修河堤后八季不再河决；同季重复的太学奏疏、裁过宗室禄赐后仍出的宗室奏疏 → 加守卫。
- 地图区域卡给耶律大石显示「召见」按钮（界面）→ 外方之人只列名。E2E：京城奏疏改写「奏上」后的断言、地图标签淡出 0.25 秒而测试只等 0.12 秒。
- 乱打仍有 1.3% 好结局 → 好结局加「民心 ≥ 60」（稳健打法约 72，乱打约 50）。

**发现与处理**
- 网页试玩：本机 Claude 解释御笔时写 `{"type": ...}`、并给出「仅叙事」「请澄清」两类非操作条目，整条诏令被驳回「缺少 op 字段」，界面还印出「None」。模板：提示词附玩家可用操作的写法，`type` 当 op 读，叙事 / 澄清成为「仅记录 / 须澄清」条款，缺 op 的摘要不写 None；实体表补地区、军队；任命在途之人时说明原因。修后同一道御笔得出「召李纲（令达后启程）、种师道改宣抚河北」两条可行条款和两条合理的澄清问题。
- 网页试玩：本机 Claude 写的纪事带 Markdown（「**起居注**」），界面原样显示 → 模板去 Markdown。
- Claude（地狱）：辽亡后仍照付「岁币（辽）」→ 辽亡事件罢岁币（已转输于金者不重复）；诸国关系整局不动 → 结盟、谢绝、助辽调整关系（不改正负号，以免误判敌对）；已亡之国不列（模板）；助辽的代价藏在后面 → 选项提示写明「金人或移兵问罪」，另设奏疏「遣使释疑」可暂止三季；「依旧 / 不问」也会被判有司稽迟 → 模板加 `immediate: true`，24 个放任选项标上；罢官者在名单里仍挂原衔 → 模板写「旧衔某某，今无官职」；「朝野戒备」分项永远是 0 → 改名「势极自缓（75 以上）」。
- GPT：同一诏书先易帅、后下军令，风险提示仍用旧帅之名 → 模板按前序条款施行后的状态判定（预览与确认都改）。
- 自玩：围燕之师在金人入燕后困于金境 → 新事件「伐燕之师引还」；金主之丧奏疏写死第 14 季、又要求军报先到，永远不出现 → 改为军报到后那一季呈上；资源到下限时事实只写「+0」→ 模板注明截断。
