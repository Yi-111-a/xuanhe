# 自玩 self-05（地狱，种子 31，引擎快照 r5）

经 MCP（`tools/selfplay.py` → `playtests/self/play3.sh` / `choose.sh`）逐季下诏，共 27 季，每季的回执与结算原文在本目录 `t*_turn.md`。

## 路线

- 宣和二年至四年：半史实路线——许金夹攻、童贯伐燕（白沟之败）、种师道再举，金先取燕京后以岁赋赎燕；张觉据平州时先纳后斩。
- 宣和五年至六年：河北困于馈运、燕山大饥，修太原、京城守具（「太原城守完固」「京城守具完备」），贬王黼、罢花石。
- 宣和七年春「金兵南下」：从李纲血书主守，张叔夜、西军勤王，窜童贯、梁师成；宣和七年秋太原陷、燕京失守、河东军退关中。
- 宣和七年冬「兵临汴京」：以李纲总领京城，从种师道坚壁不劫营，不许割三镇；金军连季「师老粮匮」。
- 宣和八年夏反击：宗泽、种师中合兵北上，河北西路之战胜，收复河北西路；秋，李纲以京师禁军出击，京西之战胜，金军北遁。
- **终局（宣和八年冬）：划河而守**——汴京未失，河东仍陷于金。
